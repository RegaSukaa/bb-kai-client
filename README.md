# Blackboard КАИ — Android-клиент учебного портала КНИТУ-КАИ

Неофициальная оболочка вокруг `https://bb.kai.ru` (Blackboard Learn 3902), сделанная так, чтобы
порталом было удобно пользоваться с телефона.

## Что умеет

- Вход на портал с сохранением сессии (cookies живут между запусками, пароль не хранится).
- MFA/двухфакторный вход, SSO-редиректы, формы и тесты — всё внутри приложения.
- Загрузка файлов в задания (системный выбор файла, множественный выбор).
- Скачивание материалов: свой HTTP-клиент с cookie сессии, файлы ложатся в «Загрузки/Blackboard»,
  PDF открывается во внешнем просмотрщике (WebView PDF не рисует).
- Камера и микрофон для вебинаров Blackboard Collaborate (разрешения запрашиваются по факту).
- Навигация: назад/вперёд/обновить/домой, аппаратная кнопка «Назад».
- Настройки: мобильный ↔ компьютерный вид сайта, размер текста 80–160 %, выход из аккаунта.
- Экран «нет связи» с повтором вместо белой страницы.

## Сборка

```bash
cd android
export JAVA_HOME=/path/to/jdk17 ANDROID_HOME=/path/to/android-sdk
./gradlew clean :app:testDebugUnitTest :app:assembleDebug
```

`./gradlew clean` обязателен перед релизной сборкой: инкрементальный упаковщик дописывает APK
и оставляет в архиве ~30 МБ мусора от прошлых сборок.

## Структура

| Файл | Что делает |
|---|---|
| `Site.kt` | адреса, UA, настройки (SharedPreferences), чистые правила |
| `WebBridge.kt` | настройка WebView, навигация, загрузка файлов, разрешения |
| `FileDownloader.kt` | скачивание с cookie через OkHttp + MediaStore |
| `DownloadNames.kt` | имя файла из Content-Disposition/URL (UTF-8, RFC 5987) |
| `BrowserScreen.kt` | весь UI: шапка, нижняя панель, настройки, сплэш, ошибка |
| `tools/make_icons.py` | иконки из кода: плитка «Bb» в золотой рамке |
